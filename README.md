# National Transit Recovery - Post-COVID Ridership Analysis

## Project Overview
This project evaluates how U.S. public transit ridership has recovered since COVID across major metro areas, using monthly filings from the FTA National Transit Database (NTD).

This analysis derives a **Recovery Index** metric: each metro's ridership benchmarked against its own 2019 baseline, where 100 = fully recovered.

See a more in-depth analysis on my Substack: https://erinjihooan.substack.com/p/national-transit-recovery-post-covid
